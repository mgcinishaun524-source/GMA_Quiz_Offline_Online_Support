## 1. Purpose and Method

This document classifies every Uncommon submission requirement as one of:

| Status | Meaning |
|---|---|
| **COMPLETE** | Present in the repository and verified with direct evidence (command output, file content, or live check). |
| **PARTIALLY COMPLETE** | Some evidence exists, but a material part of the requirement is unmet. |
| **MISSING** | Not implemented or not documented. |
| **BLOCKED** | Cannot be completed by an automated agent — requires the owner's GitHub access, credentials, approval, or human action. |
